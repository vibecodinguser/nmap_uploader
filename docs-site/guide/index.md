# Установка

Yamapper — расширение для браузера на Manifest V3. Работает в Chrome, Яндекс.Браузере и Firefox.

## Требования

- Современный браузер с поддержкой Manifest V3.
- Аккаунт Яндекс ID — расширение сохраняет файлы на ваш Яндекс Диск.

## Проверка сборки перед публикацией

Сайт должен собираться без ошибок. Команды выполняются из папки `docs-site`:

```bash
pnpm install
pnpm build
```

Результат сборки — `docs-site/.vitepress/dist`. Папка попадает в `.gitignore` и не коммитится.
