# Разработчикам

Черновик. Как собрать расширение, прогнать проверки и где живёт архитектура.

## Dev-сервер и порт 3000

`pnpm dev` (Firefox) и `pnpm dev:chrome` поднимают WXT на порту `3000` с
`strictPort: true`: если порт занят, сборка падает с ошибкой
«Port 3000 is already in use», а не переезжает на соседний порт. Так две
сборки не смешиваются молча.

Закрытие окна терминала на macOS не останавливает дочерний `node`, поэтому
после такого закрытия порт остаётся занятым. Освободить его:

```bash
pnpm dev:stop
```

Скрипт находит слушателя порта, убеждается, что это WXT или Vite, и только
тогда его останавливает. Чужой процесс на порту он не трогает: печатает его
команду и завершается с ошибкой. Другой порт можно передать аргументом:
`pnpm dev:stop 3001`.

После перезапуска сервера вкладку редактора стоит перезагрузить — у старой
страницы клиент Vite никуда не подключён.

## Chrome и Яндекс.Браузер: сборку загружают вручную

`pnpm dev:chrome` не открывает браузер: он только собирает расширение и держит
сервер на `3000`. Причина — Chrome 137+ (и Яндекс.Браузер) перестал применять
`--load-extension`, поэтому web-ext ставит dev-сборку CDP-командой
`Extensions.loadUnpacked`. Такое расширение навсегда выключается после
`browser.runtime.reload()`, а WXT вызывает его на каждую правку background,
манифеста или общего модуля (например `lib/i18n/messages/*`): расширение
«исчезало» из браузера, и помогала только перезагрузка `pnpm dev`.

Один раз загрузите сборку вручную:

1. Запустите `pnpm dev:chrome` и дождитесь первой сборки.
2. Откройте `chrome://extensions`, включите «Режим разработчика» и нажмите
   «Загрузить распакованное расширение» → `.output/chrome-mv3-dev`.

Дальше правки перезагружают обычную unpacked-установку, и она остаётся в
браузере. После перезапуска `pnpm dev` dev-WebSocket сам не переподключается
(upstream [wxt#2707](https://github.com/wxt-dev/wxt/issues/2707)): нажмите
«Обновить» у расширения в `chrome://extensions` или `Alt+R` на странице карты.
Firefox (`pnpm dev`) запускается автоматически, как раньше.
