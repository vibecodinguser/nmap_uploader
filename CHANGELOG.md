# История версий

## 1.1 — 2026-06-01

### Добавлено

- Улучшена обработка дропзоны для загрузки полигонов
- Раздел с настройками расширения
- Отображение аватара в шапке
- Возможность менять тему приложения
- Возможность изменять цвет контура загружаемого трека или полигона

### Исправлено

- Отключён silent OAuth и force_confirm
- Фиксы UI
- Убран Tailwind
- Оптимизация под LightHouse
- Адаптация тёмной темы под дефолтную тему Chrome и Yandex
