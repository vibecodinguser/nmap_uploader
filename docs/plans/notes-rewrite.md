# План: переделка заметок

Ветка: `feat/notes-rewrite`. Решения зафиксированы в ADR-0007 и ADR-0008.

## Цель

Заменить «заметки как надстройку над Блокнотом картографа» на самостоятельный слой объектов карты: 5 видов фигуры, оформление, иконки, группы, поиск, панель на 1/4 экрана с разворотом.

## Не входит в эту переделку

- импорт/экспорт GeoJSON (отложено);
- офлайн-очередь правок;
- подгруппы/дерево групп;
- совместный доступ к заметкам;
- перенос старых нативных заметок.

---

## Состояние

Шаг 1 сделан в ветке `feat/notes-rewrite`:

- домен, хранилище, background-обработчики, слой карты, хост панели и UI списка/свойств;

## 1. Контракт хранилища

Всё в папке приложения `Приложения/Блокнот картографа Народной карты/notes/`.

```
notes/index.json              манифест: заметки без геометрии + группы
notes/geometry/YYYY-MM.json   шарды геометрии по месяцу даты заметки
notes/icons/<uuid>.<ext>      пользовательские иконки (≤64 КБ, PNG/SVG, ресайз до 64×64)
```

### 1.1 Манифест

```json
{
  "version": 1,
  "updatedAt": "2026-11-14T10:00:00.000Z",
  "groups": [
    { "id": "uuid", "name": "Мосты", "color": "#1a8cff", "order": 0 }
  ],
  "notes": [
    {
      "id": "uuid",
      "kind": "Point | Line | Polygon | Square | Circle",
      "name": "14.11.2026 Точка",
      "description": "",
      "date": "14.11.2026",
      "icon": { "kind": "builtin | file", "value": "pin | uuid.png" },
      "showLabel": false,
      "style": {
        "color": "#e96b7c",
        "fillColor": "#e96b7c",
        "hatch": { "pattern": "diagonal | backDiagonal | grid | dots | horizontal", "color": "#000000", "width": 1 },
        "opacity": 1,
        "strokeWidth": 3
      },
      "groupId": "uuid | null",
      "createdAt": "2026-11-14T10:00:00.000Z",
      "updatedAt": "2026-11-14T10:00:00.000Z"
    }
  ]
}
```

~300 байт на заметку → ~1,5 МБ на 5 000. Панель читает только этот файл.

### 1.2 Шард геометрии

```json
{
  "version": 1,
  "notes": {
    "uuid": { "kind": "Point", "coords": [37.6, 55.7] },
    "uuid2": { "kind": "Line", "coords": [[37.6, 55.7], [37.7, 55.8]] },
    "uuid3": { "kind": "Polygon", "coords": [[...], [...], [...], [...]] },
    "uuid4": { "kind": "Square", "corners": [[lon, lat], [lon, lat]] },
    "uuid5": { "kind": "Circle", "center": [lon, lat], "radiusMeters": 250 }
  }
}
```

Правила:

- шард выбирается по месяцу `note.date`; при смене даты через границу месяца геометрия переносится между шардами;
- квадрат — по двум противоположным углам, стороны вдоль параллелей и меридианов;
- круг — центр + радиус в метрах, в рендер уходит дискретизация на 72 точки (и на любой зум пересчитывается заново);
- границы Диска: 8 МБ на шард; оценка одного месяца при 200 заметках/день ≈ 1,2 МБ, запас есть.

### 1.3 Мерж и запись

- каждая запись несёт `updatedAt`; при сохранении читаем манифест с Диска, сливаем по `id` (побеждает более поздний `updatedAt`), пишем;
- группы сливаются так же по `id` (у группы тоже `updatedAt`);
- запись с задержкой ~800 мс, принудительный сброс при закрытии панели и на `visibilitychange`;
- при одновременной правке **одной** заметки на двух устройствах побеждает поздняя, поля не сливаются.

### 1.4 Локальный кэш

IndexedDB, база `nmap-notes`: `manifest` (одна запись), `shards` (по ключу `YYYY-MM`), `icons` (Blob). Кэш — ускоритель: панель открывается из него, сеть догружается в фоне. Инвалидация — по `updatedAt` манифеста и версии шарда.

### 1.5 Режим просмотра

`notes_hidden_ids` остаётся в `storage.local` (ключ уже есть). Это «скрыто у меня сейчас», а не свойство заметки.

### 2.1 Сообщения

Панель (iframe) ↔ background ↔ content script карты:

| action | направление | смысл |
|---|---|---|
| `NOTES_LOAD` | панель/карта → bg | снимок: кэш сразу, затем Диск широковещательно |
| `NOTES_SAVE_NOTE` | панель → bg | upsert заметки и её геометрии |
| `NOTES_DELETE_NOTE` | панель → bg | удалить заметку и геометрию |
| `NOTES_SAVE_GROUP` / `NOTES_DELETE_GROUP` | панель → bg | группы (распустить или каскадно) |
| `NOTES_MOVE_NOTE` | панель → bg | перенос заметки в группу |
| `NOTES_UPLOAD_ICON` | панель → bg | файл иконки (base64), ≤64 КБ, png/svg/webp |
| `NOTES_SNAPSHOT` | bg → все | широковещательный снимок после изменения |
| `NOTES_RENDER` | bg → карта | манифест + шарды + скрытые id слою |
| `NOTES_VISIBILITY` | bg → карта | изменился только набор скрытых |
| `NOTES_SELECT` | карта ↔ панель | выбрана заметка или выбор снят |
| `NOTES_START_DRAW` | панель → карта | начать рисование фигуры |
| `NOTES_DRAW_FINISHED` | карта → панель | фигура нарисована, панель создаёт заметку |
| `NOTES_HIDDEN_CHANGED` | панель → bg | сохранить и перерисовать скрытие |

Центрирование карты идёт существующим действием `centerMap` (`lib/background/relay_handlers.ts`), отдельное `NOTES_LOCATE` не понадобилось.

### 2.2 Рендер

- свой слой расширения (`ymaps.GeoObjectCollection`), нативные объекты редактора не трогаем;
- стиль: `strokeColor` (цвет + прозрачность через `rgba`), `strokeWidth`, `fillColor`, `fillImageHref` для штриховки;
- **риск**: если `fillImageHref` не поддерживается — запасной путь, собственный SVG-полигон поверх карты; проверить на живой карте до шага 2;
- подписи: по умолчанию выключены, при включении скрываются на зуме < 13 и схлопываются при пересечении;
- кластеризация точек на малом зуме, упрощение линий/полигонов на дальних зумах.

## 4. Шаг 2 — Оформление и структура

1. Квадрат и круг: протяжка мышью, правка радиуса числом, дискретизация.
2. Заливка и штриховка полигонов, 5 узоров (сначала проверить `fillImageHref`, при отказе — SVG-слой).
3. Иконки: встроенный набор (30–40 штук), загрузка своих, отрисовка по центру объекта.
4. Подписи на карте: включение/выключение, схлопывание, порог зума.
5. Группы: создание, переименование, цвет, перетаскивание (HTML5 drag&drop), «распустить» / «удалить с заметками».
6. Массовые действия: скрыть/показать, перенести в группу, удалить.

## 5. Шаг 3 — Тонкое

1. Поиск по названию и описанию, живые фильтры по типу/группе/видимости, сортировка.
2. Кластеризация точек и упрощение геометрии на дальних зумах.
3. Клавиатурная навигация, a11y-прогон `vitest-axe` на панели.
4. Полная локализация `ru`/`en` (новые ключи `notesPanel.*`), проверка `tests/unit/i18n.test.ts`.
5. Полировка: пустые состояния, ошибки сети, конфликт версий, «геометрия ещё грузится».

## 7. Риски

| Риск | Что делаем |
|---|---|
| `fillImageHref` не работает | SVG-слой для штриховки (шаг 2, проверка до реализации) |
| 5 000 объектов тормозят карту | кластеризация и упрощение (шаг 3); до этого — ограничение видимых объектов и подписей |
| Медленный Диск | кэш IndexedDB, манифест отдельно от геометрии |
