# 0010: Заметки живут в отдельной папке приложения, а не внутри Блокнота

Контекст: ADR 0007 поселил хранилище заметок в `Приложения/Блокнот картографа Народной карты/notes`
— «рядом с Блокнотом», но фактически внутри его папки. Трекер редактора строит список треков из
подкаталогов папки Блокнота: в его настройках видно «Заметки от 16.11.2026» для каждой даты и
«Заметки «notes»» для папки заметок. Для выбранного трека трекер читает `index.json` подкаталога
как данные трека (`points` и `paths`) и рисует слой. Манифест заметок в этой роли ломал отрисовку:

```
TypeError: Cannot convert undefined or null to object
    at Object.keys
    at _.$Eca (tracker-bundle...)
```

`Object.keys(trackData.points)` получал `undefined`, потому что в манифесте заметок нет `points`.
Кроме того, трек можно удалить из настроек трекера — вместе с папкой заметок.

Решение:
1. Перенести хранилище заметок в собственную папку приложения:
   `Приложения/Nmap Uploader/notes` (`index.json`, `geometry/<гггг-мм>.json`, `icons/<uuid>.<ext>`).
   Трекер смотрит только внутрь папки Блокнота и эту папку не видит.
2. Сделать одноразовую миграцию: если в старом месте есть `notes/index.json`, а в новом нет —
   перенести папку целиком одним запросом `POST /v1/disk/resources/move`. Шарды, манифест и иконки
   едут вместе, перечислять и перезагружать файлы не нужно. Если заметки уже на новом месте,
   старая папка переносится в `Приложения/Nmap Uploader/legacy-notes-<время>`, чтобы перестать
   мешать трекеру, но не потерять данные.
3. Запускать миграцию в фоне при старте расширения (если есть токен) и перед первым чтением
   заметок. Отметка «перенос сделан» хранится в `storage.local` по id пользователя: background
   просыпается часто, и без неё каждый запуск делал бы запросы к Диску; при входе другим
   аккаунтом миграция выполняется заново.
4. Ошибку миграции не глотать при загрузке заметок: если перенос не удался, панель показывает
   ошибку хранилища, а не пустой список — данные целы в старом месте, попытка повторится.

Причина: папка заметок не должна попадать в область, которую редактор интерпретирует как свои
данные. Это не только косметика консоли: трекер мог удалить заметки вместе с «треком».

Следствие: в README доступ к Диску описан двумя папками приложения. ADR 0007 остаётся в силе в
части «своё хранилище, свой формат, свой кэш»; меняется только расположение папки.
