# 0015: Клики для разреза берутся из DOM, а не из событий карты

Контекст: в живом редакторе инструмент разреза (ADR 0012–0014) не работал:
кнопка нажата, состояние `ready:…`, а клик по линии ничего не делает. Инструмент
подписывался на событие `click` карты (`ymaps.Map.events`). У `ymaps` это событие
срабатывает только на пустом месте карты: клик по геообъекту получает сам
геообъект, до карты он не доходит. Редактируемая часть контура — геообъект, то
есть резать можно было только там, где линии нет.

Проверено на `ymaps` 2.1.79 (версия, которую грузит НЯК) вне НЯК; подробности и
таблица — `docs/nmaps-editor-internals.md`, раздел 4.5. Автотесты ошибку не
ловили: они звали обработчик клика напрямую, а тест подписки проверял, что вызван
`events.add('click', …)`, — то есть закреплял сам дефект.

Решение:
1. Пока режим включён, инструмент слушает DOM-событие `click` на `document` в
   фазе перехвата. Точка клика переводится в глобальные пиксели карты через
   `map.converter.pageToGlobal`.
2. Клик берётся, только если его цель — панель событий карты
   (`[class*="events-pane"]` внутри контейнера карты). Этому элементу браузер
   отдаёт клики по карте, линиям и вершинам; меню вершины, балуны и интерфейс
   поверх карты в него не входят.
3. Клик после перетаскивания не считается: запоминается точка нажатия, и при
   сдвиге больше 5 px клик пропускается. Правая и средняя кнопки не режут.
4. Клик, попавший в линию (разрез сделан, поставлена первая граница, отказ из-за
   короткой части), редактору не отдаётся: распространение останавливается.
   Клик мимо линии идёт редактору как обычно.
5. С флагом `nmap-veg-cut-debug` каждый клик пишется в консоль с исходом или
   причиной, по которой он не взят.
6. Тесты режима кликают по элементу карты настоящим DOM-событием; прямой вызов
   обработчика в них больше не используется.

Причина: слушать `map.geoObjects.events` недостаточно — неизвестно, в какую
коллекцию редактор НЯК кладёт свои геообъекты, а карту пришлось бы слушать
отдельно. DOM-событие одно на все случаи и приходит раньше, чем его увидит
редактор. Не отдавать редактору обработанный клик нужно затем, чтобы разрез по
вершине не открывал её меню, а один клик не имел двух последствий.

Следствие: в режиме разреза клик по вершине режет линию в этой вершине, а меню
вершины не открывается; чтобы открыть меню, режим нужно выключить.
Перетаскивание вершин и карты в режиме разреза работает как обычно.

Ограничения:
- Признак «это карта» опирается на имя класса панели событий `ymaps`. Версия 2.1
  заморожена; если НЯК сменит API карт, инструмент перестанет брать клики —
  причина будет видна в логе кликов (`не карта`).
- Поведение проверено на настоящей карте `ymaps` с редактором-заглушкой
  (`docs/nmaps-editor-internals.md`, раздел 12.2). В живом редакторе НЯК — только
  чек-листом `docs/checklists/vegetation-cut-smoke.md`.
