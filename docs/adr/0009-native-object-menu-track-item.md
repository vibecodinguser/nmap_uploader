# 0009: Пункт «Отслеживать» в нативном меню объекта

Контекст: объект добавляется в «Мои объекты» вручную — через поле ввода id во вкладке
трекера. Пользователь, который уже открыл карточку нужного объекта, вынужден копировать
его идентификатор из URL. При этом меню «Ещё» (`nk-icon_id_more`) в шапке карточки
рендерится порталом редактора (`.nk-portal > .nk-popup > .nk-popup__content > .nk-menu`),
переиспользуется между открытиями (попап не создаётся заново, а получает класс
`nk-popup_visible`) и закрывается только кликом по карте.

Решение:
1. Не подменять нативное меню и не рисовать своё: расширение дописывает один пункт
   в уже открытый попап. Пункт получает нативные классы `nk-menu-item`, поэтому
   наследует вид и тёмную тему; свой CSS — только для неактивного состояния.
2. Определять объект в момент клика по иконке «Ещё»: id из hash редактора
   (`#!/objects/<id>`), название — из шапки карточки. Попап портала уже не связан
   с карточкой, поэтому в момент его появления объект восстановить неоткуда.
3. Считать меню объектным по любому из узнаваемых пунктов («Копировать», «Поделиться»,
   «Сообщить об ошибке»), а не по полному набору: у водоёмов и АТД редактор не показывает
   «Копировать» — меню там «Удалить», «Поделиться», «Сообщить об ошибке». Сразу после клика
   по «Ещё» действует «доверенное окно»: меню считается объектным без проверки пунктов,
   поэтому пункт появляется и у категорий с непривычным набором действий. Меню справки,
   карты и фильтров содержат `.nk-menu`, но таких пунктов в них нет.
4. Добавлять объект оптимистично: id пришёл из редактора, поэтому проверка
   существования через API и CSRF-токен не нужны. Название берётся из карточки,
   категорию дотягивает ближайший опрос; история до добавления не считается новой.
5. Показывать ошибки (дубликат, лимит, неизвестный id) коротким сообщением поверх
   страницы: попап после клика остаётся открытым, но текст в пункте меню для ошибки
   не годится.

Причина: добавление в наблюдение должно быть доступно в один клик из карточки
объекта и не зависеть от сети или CSRF-токена, а нативное меню остаётся
единственным источником разметки и поведения.
