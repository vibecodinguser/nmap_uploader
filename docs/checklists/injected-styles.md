# Чеклист: инжектируемые стили

Ручная проверка того, что рефакторинг стилей не изменил внешний вид.
Автотесты (`tests/unit/styles/`) ловят изменения текста CSS, но не то, как он
лег на страницу Народной карты.

## Подготовка

1. `npm run check` — lint, stylelint, типы, тесты.
2. `npm run build` (Chrome/Yandex) и `npm run build:firefox`.
3. Загрузить `.output/chrome-mv3` как распакованное расширение, открыть
   `https://n.maps.yandex.ru/` и войти в аккаунт.
4. Повторить для Firefox (`.output/firefox-mv2`), если он есть под рукой.

## Панель наблюдения (`object-tracker`)

- [ ] Вкладка «Мои объекты» появляется в сайдбаре, индикатор непрочитанного —
      жёлтая точка справа от подписи.
- [ ] Панель прокручивается, карточки ленты идут от края до края.
- [ ] Переключатель режимов: активная вкладка выделяется полосой, полоса
      сдвигается под выбранный режим.
- [ ] Поле добавления объекта: рамка и внутренний control совпадают, углы
      скруглены на 4px, фокус — жёлтая обводка вокруг обёртки, а не внутри.
- [ ] Ошибка ввода — красный текст, предупреждение — жёлтая плашка.
- [ ] Тёмная тема редактора: ссылки голубые, серый текст читаем, рамки видны.

## Лента правок (`feeds-filter`)

- [ ] Ряд фильтров: наш селект статуса и селект действий стоят в одну строку
      с фильтрами редактора, растянуты по ширине, высота совпадает.
- [ ] При выключенном фильтре ряд фильтров выглядит как нативный (правила
      хоста не применяются без нашего контрола).
- [ ] Открыть попап фильтра: тёмный фон, серый текст, hover — светлее,
      выбранный пункт — жирный, счётчик справа, галочка в селекте.
- [ ] Спиннер загрузки — жёлтое кольцо.
- [ ] Секция периода: кнопки 1/3/7 дней, активная — жёлтая рамка и текст,
      кнопка остановки — красноватая.
- [ ] Скрытие карточек по фильтру работает.

## Меню геосервисов и раздельный вид (`go-to`)

- [ ] Кнопка в тулбаре: иконка по центру, при наведении ярче.
- [ ] Меню: светлый попап, пункты с иконками, hover — жёлтая подсветка.
- [ ] Тултип: тёмный, светлый текст, появляется с fade-in.
- [ ] Кнопка «раздельный вид»: карта слева на 50vw, Nakarte справа.
- [ ] Маркеры курсоров видны в обеих половинах, баннер по центру;
      при зуме > 18 баннер краснеет.
- [ ] Попап загрузки полигонов открывается поверх, iframe не обрезан.

## Плашка лимита вершин (`point-counter`)

- [ ] Счётчик точек отображается, цвет меняется по порогу.
- [ ] При включённом подавлении плашка лимита не мигает и не показывается.
- [ ] Выключить подавление — плашка возвращается.

## Перекраска контуров (`stroke-color`)

- [ ] Линии, нарисованные magenta, перекрашиваются в выбранный цвет.

## После проверки

- [ ] Перезагрузить расширение (`chrome://extensions` → «Обновить») и убедиться,
      что на странице не осталось `<style id="nmap-…">` и атрибута
      `data-nmap-hide-system-banner` — teardown отработал.
- [ ] Переключить тему расширения и системную тему — инжектируемые элементы
      не «залипают» в одном цвете.
