# Проверка: заметки на живой карте

Ручной прогон для переделки заметок и её рефакторинга
(`docs/plans/notes-rewrite.md`, `docs/plans/notes-refactor.md`).

Как пользоваться: пройти пункты по порядку и отметить результат. Пункты с
пометкой **новое** проверяются впервые — автоматических тестов на них нет или
они не могут подтвердить работу карты.

Подготовка:

1. `pnpm dev`, расширение загружено, вход в Яндекс выполнен.
2. Открыта вкладка Народной карты (редактор), панель заметок ещё закрыта.
3. В `notes/` на Диске либо пусто, либо есть тестовые данные, которые не жалко
   потерять.
