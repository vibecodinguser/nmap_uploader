# Snapping к полигону заметки

## Цель

Добавить в штатный режим рисования полигонов Народной карты прилипание создаваемого контура к рёбрам активной полигональной заметки из Блокнота картографа.

## Пользовательское поведение

- Клик по строке полигональной заметки делает её активной целью snapping.
- Активность заметки не зависит от раскрытия её описания.
- При выборе другой полигональной заметки цель snapping сразу меняется.
- При смене даты, удалении активной заметки или выборе заметки другого типа snapping отключается.
- Во время штатного рисования НЯК курсор прилипает к ближайшей точке любого ребра активного полигона, если расстояние до неё не превышает 10 экранных пикселей.
- В точке прилипания отображается небольшой маркер.
- Вне радиуса snapping штатное рисование работает без изменений.

## Архитектура

### Панель заметок

`NotesTab` хранит идентификатор активной заметки отдельно от состояния раскрытых строк. При выборе строки панель отправляет активный полигон вместе с остальными данными отрисовки. Передаются идентификатор заметки и её координаты; для неподходящей или отсутствующей цели передаётся пустое значение.

### Мост в страницу

Существующий поток `DRAW_MAP_OBJECTS` / `nmaps:drawObjects` расширяется полем активной цели. Content script передаёт данные в `MAIN world`, не сохраняя их в DOM и не выполняя геометрические вычисления.

### Движок snapping

Геометрические вычисления выделяются в отдельный модуль без зависимости от DOM и API Яндекс Карт. Модуль:

1. принимает позицию курсора и экранные координаты вершин полигона;
2. проецирует курсор на каждый сегмент, включая замыкающий;
3. выбирает ближайшую допустимую проекцию;
4. возвращает исходную либо скорректированную позицию и расстояние до цели.

В `MAIN world` координаты активного полигона переводятся в экранные через конвертер найденного экземпляра карты. При перемещении, масштабировании и изменении размеров карты экранная геометрия пересчитывается.

### Интеграция со штатным редактором

Основной способ — перехват координат, которые штатный редактор использует для предпросмотра и установки очередной вершины. В пределах порога редактор получает координату ближайшей точки ребра.

Поскольку публичный API Яндекс Карт не предоставляет регистрацию пользовательских целей snapping, интеграция изолируется в адаптере внутренних API НЯК. Адаптер проверяет наличие ожидаемых методов перед установкой перехватов.

Если подмена координат предпросмотра недоступна, резервный адаптер корректирует последнюю добавленную вершину сразу после клика. Одновременно активен только один способ интеграции.

## Отображение

Полигон заметки продолжает отображаться существующим синим стилем. При нахождении цели в радиусе 10 px поверх карты показывается небольшой маркер в рассчитанной точке. Маркер не принимает события указателя и удаляется при выходе из радиуса, завершении рисования, смене цели или отключении адаптера.

## Отказоустойчивость

- Ошибка поиска карты, преобразования координат или установки адаптера не блокирует штатное рисование.
- Некорректная геометрия, менее трёх уникальных вершин и нечисловые координаты не используются для snapping.
- Все перехваченные методы восстанавливаются при повторной инициализации или уничтожении карты.
- Повторная доставка одного события не создаёт дублирующие обработчики.
- Диагностические ошибки выводятся с префиксом расширения и не показываются пользователю, если штатное рисование продолжает работать.

## Тестирование

Unit-тесты проверяют:

- проекцию на горизонтальный, вертикальный и наклонный сегменты;
- ограничение проекции концами сегмента;
- выбор ближайшего из нескольких сегментов;
- замыкающее ребро полигона;
- поведение внутри, на границе и вне порога 10 px;
- обработку вырожденных сегментов и некорректных координат.

Интеграционные тесты проверяют:

- передачу активной заметки из панели в `MAIN world`;
- смену и сброс активной цели;
- отсутствие повторной установки обработчиков;
- включение резервного адаптера при недоступности основного;
- сохранение штатного поведения при ошибке интеграции.

Ручная проверка выполняется в актуальном редакторе НЯК: выбор заметки, начало рисования нового полигона, прилипание к середине и концам каждого ребра, масштабирование и перемещение карты, завершение и отмена рисования.

## Ограничения

Решение зависит от внутренних механизмов редактора НЯК, поскольку публичный API не поддерживает пользовательские цели snapping. Адаптер изолирует эту зависимость, но после обновлений НЯК может потребоваться его корректировка. Функция применяется только к полигональным заметкам и только во время штатного рисования полигонов.
