# Редизайн карточки заметки

Дата: 2026-11-18

## Задача

Детальная страница заметки (`NoteProperties` + `NoteAppearance`) должна быть
адаптивной на всю ширину панели: на широкой панели блоки идут в три колонки без
пустых дыр, на средней — в две, на узкой — в одну. Блок «Поверхность» убирается,
его флажки разносятся по местам, к которым они относятся.

Модель данных не меняется: `style.fillColor: string | null`,
`style.hatch: NoteHatch | null`, `showLabel: boolean`.

## Что сейчас не так

- Одна точка перелома (900 px): восемь колонок сразу превращаются в один
  длинный столбец, промежуточной раскладки нет.
- «Поверхность» стоит одна на третьей линии, справа шесть пустых колонок.
  Внутри — три флажка про разное: заливка, штриховка, подпись.
- Места заданы числовыми `grid-area`, любая перестановка ломает раскладку.

## Раскладка

Сетка `.notes-panel__properties-grid` переходит на `grid-template-areas`.
Каждый блок получает имя области: `name`, `desc`, `color`, `pattern`, `icon`,
`stroke`.

| Ширина iframe | `grid-template-columns` | `grid-template-areas` |
|---|---|---|
| ≥ 1200 px | `minmax(0, 2fr) minmax(0, 1fr) minmax(0, 1fr)` | `"name color icon" "desc pattern stroke"` |
| 700–1199 px | `repeat(2, minmax(0, 1fr))` | `"name color" "desc pattern" "icon stroke"` |
| < 700 px | `minmax(0, 1fr)` | `"name" "desc" "color" "pattern" "icon" "stroke"` |

Правила:

- `minmax(0, …)` обязателен: сетка иконок и плитки узоров задают минимальную
  ширину содержимого, без него колонки выйдут за панель.
- Отсутствующий у вида блок оставляет свою область пустой, соседи не
  сдвигаются. У точки нет `pattern` и `stroke`, у линии нет `pattern`.
- Описание растягивается на высоту строки (`align-self: stretch`, textarea с
  `flex: 1`), чтобы рядом с высоким блоком не оставалось дыры.
- Точки перелома — медиа-запросы по ширине: панель живёт в своём iframe,
  ширина его окна и есть ширина панели.
- Сетка иконок уже на `auto-fill`, менять её не нужно. Выравнивание по левому
  краю на узкой ширине сохраняется.

### Область `name`

Обёртка `.notes-panel__identity` с названием, группой и флажком «Подпись на
карте». Название и группа стоят в ряд (`flex-wrap: wrap`, название
`flex: 2 1 220px`, группа `flex: 1 1 160px`): когда места мало, группа
переносится под название. Флажок — отдельной строкой под ними.

## Компоненты

### `NoteProperties`

- Название, группа и флажок «Подпись на карте» собираются в
  `.notes-panel__identity` (область `name`).
- Флажок «Подпись на карте» переезжает сюда из `NoteAppearance` с той же
  логикой (`onPatch({ showLabel })`). Он есть у всех видов заметок.
- Описание — область `desc`.

### `ColorPicker`

- Необязательный проп `children`, рисуется под палитрой внутри того же
  `fieldset`.

### `NoteAppearance`

- Блок «Поверхность» удаляется.
- Флажок «Заливка» передаётся в `ColorPicker` как `children`, только при
  `isFilledKind(kind)`. Логика прежняя: включение ставит
  `fillColor = resolved.color`, выключение — `null`.
- Блок «Узор» показывается при `isFilledKind(kind)` всегда, независимо от
  того, есть ли штриховка.
- Иконка и границы — без изменений по поведению.
- Обёртка `.notes-panel__appearance` с `display: contents` сохраняется.

### `HatchPicker`

- Становится самостоятельным блоком: `fieldset.notes-panel__field-group
  .notes-panel__field-group--pattern` с заголовком
  `.notes-panel__field-group-title` «Узор».
- Пропсы: `value: NoteHatch | null`, `onChange: (hatch: NoteHatch | null) =>
  void`.
- Первая плитка — «Без узора» (`aria-label` из `notesPanel.hatchNone`),
  `aria-pressed` при `value === null`, клик даёт `onChange(null)`. Рисунок
  плитки — тот же знак, что у «без иконки» в `IconPicker`.
- Клик по узору даёт `onChange({ pattern })`, в том числе когда `value === null`.

## i18n

- Добавить `notesPanel.hatchNone`: «Без узора» / «No pattern».
- Удалить `notesPanel.groupFill` и `notesPanel.hatch`, если после правки они
  нигде не используются.

## Тесты

- `fill_and_hatch_ui.test.tsx`:
  - флажок «Штриховка» заменяется плиткой «Без узора»: клик даёт `hatch: null`,
    при `hatch === null` она `aria-pressed="true"`;
  - клик по узору при `hatch === null` даёт `hatch: { pattern }`;
  - блок «Узор» есть у полигона, квадрата и круга, его нет у линии и точки;
  - флажок «Заливка» находится внутри блока «Цвет», его нет у линии и точки.
- `panel_components.test.tsx`: флажок «Подпись на карте» есть у всех видов и
  меняет `showLabel`.
- a11y-тест компонентов проходит на новой разметке.
- Проверки: `biome`, `stylelint`, `tsc`, `vitest`.

Раскладку по ширине happy-dom не проверяет. После реализации — скриншоты
собранной панели на ширинах 1400, 900 и 500 px.
