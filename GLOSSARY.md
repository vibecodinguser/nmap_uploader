# nmap_uploader (Блокнот картографа НЯК)

Браузерное расширение для Народной карты Яндекса (НЯК), предоставляющее инструменты загрузки геоданных (KML, GPX, Shapefile, GeoJSON и др.), фильтрации лент правок, синхронизации с картографическими сервисами и управления заметками.

## Language

**Блокнот картографа**:
Интерфейс и внутреннее хранилище объектов картографа на Народной карте Яндекса.
_Avoid_: Заметки карты, локальный блокнот

**Геоконвертер (Geo Converter)**:
Модуль трансляции исходных форматов геоданных (KML, GPX, Shapefile, GeoJSON, TopoJSON, WKT) во внутреннюю структуру объектов Блокнота картографа (`ProcessResult`).
_Avoid_: Парсер полигонов, загрузчик

**Пайплайн загрузки (Upload Pipeline)**:
Последовательность шагов: валидация файла -> парсинг/конвертация -> формирование полезной нагрузки (`ProcessResult`) -> отправка через API/сессию в Народную карту.
_Avoid_: Заливка, сохранение

**Лента правок**:
Поток событий изменений объектов на Народной карте Яндекса (`map-feeds-filter`, `user_feeds_filter.ts`).
_Avoid_: Активность, история, таймлайн

**Слой Народной карты**:
Векторные и растровые данные геометрии (полигоны, линии, точки), отображаемые на хост-странице Народной карты.
_Avoid_: Подложка, геослой

**Content Script**:
Скрипт расширения, выполняющийся в изолированном контексте страницы Яндекс.Карт с прямым доступом к DOM хоста.
_Avoid_: Инжектор, плагин

**Background Service Worker**:
Фоновый процесс расширения (`entrypoints/background.ts`), координирующий долгие операции, хранилище настроек и сетевые запросы.
_Avoid_: Сервер, бэкенд

**Адаптер хост-страницы (Page Adapter)**:
Слой изоляции для взаимодействия со структурой DOM или глобальными объектами Народной карты (модулями webpack, инжектами в контекст страницы).
_Avoid_: Хак, инъекция

**Раздельный вид (Split View)**:
Режим синхронного отображения Народной карты (слева) и сервиса Nakarte в iframe (справа) с трансляцией координат, зума и позиций курсоров.
_Avoid_: Сплит, двойной экран, сплит-окно

**Координатор вьюпорта (Viewport Coordinator)**:
Механизм пересчета размеров контейнера карты (`50vw` / `100vw`) и центрирования тайлов через API Яндекс.Карт (`fitToViewport()`, `setCenter()`) при смене режимов экрана.
_Avoid_: Ресайзер, хак тайлов
