# Загрузчик в Блокнот картографа Народной карты

Расширение для браузера (manifest v3), которое загружает геоданные в [Блокнот картографа](https://yandex.ru/support/nmaps/ru/map-blocknot.html) редактора [Народной карты Яндекс](https://n.maps.yandex.ru/).

При загрузке файла он автоматически преобразуется в формат, понятный блокноту картографа, и сохраняется в его папке на Яндекс Диске. Папка `Приложения/Блокнот картографа Народной карты` создается при первой загрузке данных. Внутри этой папки файлы организованы по папкам с датами в формате `гггг-мм-дд`, когда они были загружены.

## Дополнительно

В настройках расширения можно включить дополнительные возможности и функции:

- **Раздельный вид** — разделяет окно на две части, в одной из которых открыт редактор, а во второй посредством nakarte.me отображаются исторические карты и спутниковые снимки;
- **Кнопка «Заметки»** — добавляет в нижнюю панель кнопку, по клику на которую можно управлять загруженными данными;
- **Автообновление после загрузки** — автоматически перезагружает страницу редактора при каждой загрузке данных в Блокнот;
- **Внешние геосервисы** — позволяет выбрать необходимые внешние геосервисы и настроить их порядок в меню перехода;
- **Обводка контура** — настраивает цвет контура и заливки загруженных в Блокнот объектов.

## Возможности

- **Конвертация** — конвертирует поддерживаемые форматы в формат Блокнота;
- **Загрузка** — автоматически загружает сконвертированные данные в Блокнот (Яндекс.Диск);
- **Структурирование** — позволяет добавлять описания и организовывать ваши заметки по датам;
- **Трассировка** — выбранный полигон из Блокнота поддерживает штатную функцию «Трассировка» в редакторе;
- **Форматы** — Shapefile, GeoJSON, GPX, KML, KMZ, TopoJSON, WKT;
- **Геометрии** — Point, MultiPoint, LineString, MultiLineString, Polygon, MultiPolygon, GeometryCollection.

## Безопасность и приватность

- **Доступ к Яндекс.Диску** — расширение записывает данные только в папку приложения `Приложения/Блокнот картографа Народной карты`. Другие файлы и папки на Диске не читаются и не изменяются.
- **OAuth-токен** — хранится локально в браузере (`storage`) до выхода из аккаунта в панели расширения. Отозвать доступ можно в [настройках Яндекс ID](https://id.yandex.ru/) для приложения расширения.
- **Обработка файлов** — геоданные конвертируются на вашем устройстве; на Диск отправляется только сформированный `index.json`.
- **Сетевые запросы** — расширение обращается к доменам, указанным в манифесте: `n.maps.yandex.ru`, API Яндекс.Диска и OAuth, а также (по желанию пользователя) к внешним картографическим сервисам через меню «Перейти» и split-view с `nakarte.me`.
- **Разрешения** — `identity` (вход через Яндекс ID), `storage` (настройки и сессия), `scripting` / `tabs` / `activeTab` (работа панели и content scripts на странице редактора Народной карты).
