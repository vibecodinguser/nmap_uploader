# Загрузчик в Блокнот картографа Народной карты

Расширение для браузера (manifest v3), которое загружает геоданные в [Блокнот картографа](https://yandex.ru/support/nmaps/ru/map-blocknot.html) редактора [Народной карты Яндекс](https://n.maps.yandex.ru/).

При загрузке файла он автоматически преобразуется в формат, понятный блокноту картографа, и сохраняется в его папке на Яндекс Диске. Папка `Приложения/Блокнот картографа Народной карты` создается при первой загрузке данных. Внутри этой папки файлы организованы по папкам с датами в формате `гггг-мм-дд`, когда они были загружены.

## Возможности

- **Конвертация** — конвертирует Shapefile, GeoJSON, GPX, KML, KMZ, TopoJSON, WKT в формат Блокнота;
- **Загрузка** — автоматически загружает сконвертированные данные в Блокнот (Яндекс.Диск);
- **Настройки** — попап в шапке редактора среди нативных кнопок: оформление, заметки, НСПД, лента правок, счётчик вершин, наблюдение за объектами и внешние геосервисы;
- **Трассировка** — выбранный полигон из Блокнота поддерживает штатную функцию «Трассировка» в редакторе;
- **Загрузка АТД** — Загрузка различных типов АТД из Национальной системы пространственных данных;
- **Геометрии** — поддержка Point, MultiPoint, LineString, MultiLineString, Polygon, MultiPolygon, GeometryCollection.
- **Раздельный вид** — разделяет окно на две части, в одной из которых открыт редактор, а во второй посредством nakarte.me отображаются исторические карты и спутниковые снимки; выбранные в Nakarte слои и настройки запоминаются между открытиями;

## Дополнительно

В настройках расширения можно включить дополнительные возможности и функции:

- **Кнопка «Заметки»** — добавляет в нижнюю панель кнопку, по клику на которую можно управлять загруженными данными, а в панели выбора категории — плитку «Заметки» для создания новой заметки (beta);
- **Внешние геосервисы** — позволяет выбрать необходимые внешние геосервисы и настроить их порядок в меню перехода;
- **Подсчёт вершин** — считает оставшееся количество вершин до лимита; у многочастных полигонов учитывает только активную часть, а у объектов из нескольких линий счётчик не показывается;
- **Наблюдение за объектами** — добавляет в «Мои объекты» историю правок выбранных объектов: вручную по id или пунктом «Наблюдать» в меню «Ещё» карточки объекта (у наблюдаемого объекта он называется «Не наблюдать»);

## Безопасность и приватность

- **Доступ к Яндекс.Диску** — расширение пишет только в две папки приложений: `Приложения/Блокнот картографа Народной карты` (загруженные геоданные) и `Приложения/Nmap Uploader` (заметки и их иконки). Другие файлы и папки на Диске не читаются и не изменяются.
- **OAuth-токен** — хранится локально в браузере (`storage`) до выхода из аккаунта в панели расширения. Отозвать доступ можно в [настройках Яндекс ID](https://id.yandex.ru/) для приложения расширения.
- **Обработка файлов** — геоданные конвертируются на вашем устройстве; на Диск отправляется только сформированный `index.json`.
- **Сетевые запросы** — расширение обращается к доменам, указанным в манифесте: `n.maps.yandex.ru`, API Яндекс.Диска и OAuth, а также (по желанию пользователя) к внешним картографическим сервисам через меню «Перейти» и split-view с `nakarte.me`.
- **Шрифт интерфейса** — панели подгружают веб-шрифт редактора (`Yandex Sans Text`) с официального CDN `yastatic.net`: это те же файлы, что использует сама Народная карта. Запрос не передаёт данных, разрешений в манифесте не требует и идёт только при открытии панели; без сети интерфейс остаётся на системном Arial.
- **Доступ к НСПД** — домен `nspd.gov.ru` запрашивается только при включении функции «Загрузка из НСПД» в настройках: тумблер включён по умолчанию, а доступ спрашивается по кнопке «Разрешить доступ», когда его ещё нет. Это необязательное разрешение: без него кнопка не появляется, а расширение продолжает работать как обычно.
- **Доступ к Яндекс.Диску** — домены Яндекса и `identity` тоже необязательные и запрашиваются только при включении «Заметок». «Загрузка из НСПД» просит лишь домен `nspd.gov.ru`: сам НСПД работает и без Диска, а выгрузка объектов в Блокнот попросит доступ к Яндексу отдельно. Пока функции выключены, расширение не обращается к Яндексу и не открывает окно входа; выключение функций разрешения не отзывает.
- **Разрешения** — при установке запрашиваются только `storage` (настройки и сессия), `scripting` / `tabs` / `activeTab` (работа панели и content scripts на странице редактора Народной карты) и доступ к `n.maps.yandex.ru` и `nakarte.me`.
